⚔ ADVERSARIAL SEARCH

Game elemen: state, action, terminal test, utility function

MAX = kamu (inginkan nilai tertinggi) | MIN = lawan (inginkan nilai terendah)

Zero-sum: keuntungan MAX = kerugian MIN

🎯 MINIMAX
MINIMAX(n) =
  Utility(n) if TERMINAL(n)
  max { MINIMAX(s) : s ∈ SUCC(n) } if MAX node (△)
  min { MINIMAX(s) : s ∈ SUCC(n) } if MIN node (▽)

Cara: DFS sampai leaf → propagasi nilai ke atas

MAX node: ambil nilai TERBESAR dari anak
MIN node: ambil nilai TERKECIL dari anak

Kompleksitas: Time O(bd) | Space O(b·d)

✂ ALPHA-BETA PRUNING
α = lower bound MAX (best MAX found so far) → init -∞
β = upper bound MIN (best MIN found so far) → init +∞
ATURAN PRUNING:
MAX node n: STOP expand jika α(n) ≥ β (dari ancestor)
MIN node n: STOP expand jika β(n) ≤ α (dari ancestor)
Update α dan β:
Di MAX node: α ← max(α, nilai anak)
Di MIN node: β ← min(β, nilai anak)
Turunkan (α,β) saat masuk ke child node
Algoritma tracing step-by-step:
  1. Start root: α=-∞, β=+∞
  2. Expand DFS kiri ke kanan
  3. Di leaf: return nilai ke parent
  4. MAX node: terima nilai anak, update α. Cek α≥β → prune saudara kanan
  5. MIN node: terima nilai anak, update β. Cek β≤α → prune saudara kanan
  6. Pass (α,β) yang terupdate ke child berikutnya
Node X = dipruning → tidak perlu dihitung
Nilai root = nilai minimax optimal (sama dengan tanpa pruning)
📖 CONTOH TRACING α-β & GAME TREE
Tracing:
1. B dapat E=4 → β=min(∞,4)=4. F=5 ≥ β=4 → B=4.
2. A(MAX) dapat B=4 → update α=max(-∞,4)=4.
3. C(MIN) bawa α=4. C dapat G=6 → β=min(∞,6)=6.
4. H(MAX) bawa α=4, β=6. H dapat nilai (L=3, M=4, N=7).
5. Saat N=7, H update α=7. Karena α(7) ≥ β(6), PRUNE child H selanjutnya (O=9)!
6. C dapat H=7, nilai C = min(6,7) = 6.
7. A(MAX) dapat B=4, C=6 → Nilai akhir A = max(4,6) = 6.
🧩 CONSTRAINT SATISFACTION PROBLEM (CSP)
CSP = (X, D, C) X = {X₁,...,Xₙ} — variabel yang mau diisi D = {D₁,...,Dₙ} — domain nilai tiap variabel C = {C₁,...,Cₘ} — batasan (constraints)

Solusi: complete assignment yang MEMENUHI SEMUA constraints

Consistent: assignment tidak melanggar constraint apapun

Contoh: Map Australia
• X: {WA, NT, Q, NSW, V, SA, T}
• D: {red, green, blue}
• C: Tetangga berbeda warna (e.g., WA ≠ NT)
• T (Tasmania): Independent (tidak bertetangga)
📊 JENIS CONSTRAINT & GRAPH
Tipe Jumlah Var Contoh
Unary 1 var SA ≠ green
Binary 2 var SA ≠ WA
Higher-order >2 var Alldiff(F,T,U,W,R,O)
Preference (soft) any red lebih baik dari green

Constraint graph: node = variabel, edge = binary constraint antar 2 variabel

Manfaat: deteksi independent subproblem → selesaikan terpisah

🔄 BACKTRACKING SEARCH
BACKTRACK({}, csp): if assign complete → return assign var ← SELECT-UNASSIGNED-VARIABLE(csp, assign) for each val in ORDER-DOMAIN-VALUES(var, csp): if val KONSISTEN dengan assign: assign[var] = val result ← BACKTRACK(assign, csp) if result ≠ failure → return result remove {var=val} dari assign return failure

Idea 1: One variable at a time (commutative)

Idea 2: Check constraints as you go (incremental)

📌 VARIABLE & VALUE ORDERING
SELECT-UNASSIGNED-VARIABLE (pilih variabel):
MRV (Minimum Remaining Values) = Most Constrained
Pilih var dengan nilai legal PALING SEDIKIT tersisa
→ "fail-first": deteksi kegagalan lebih awal
MCV (Most Constraining Variable) = tiebreaker MRV
Pilih var yang punya PALING BANYAK constraint ke var lain
→ pilih SA karena punya 5 constraint di map coloring
ORDER-DOMAIN-VALUES (pilih nilai):
LCV (Least Constraining Value)
Pilih nilai yang menghapus PALING SEDIKIT pilihan dari neighbor
→ pilih nilai yang biarkan neighbor punya pilihan terbanyak
→ "fail-last": tetap buka opsi sebesar mungkin
🔍 FORWARD CHECKING (FC)

Setelah assign Xᵢ = v:

  • Untuk setiap tetangga Xⱼ (unassigned): hapus nilai dari Dⱼ yang tidak konsisten dengan v
  • Jika Dⱼ = ∅ → LANGSUNG BACKTRACK!
Contoh: X1=1 (4-Queens) After assign X1=1, hapus dari neighbor: X2: hapus 1(same row), 2(diag) → X2={3,4} X3: hapus 1,2,3 → X3={3,4} → wait: hapus row1, diag+1, diag-1 X4: hapus 1,2,3,4... [sesuai constraint queen]
FC hanya cek arc dari variabel yang baru di-assign
Tidak deteksi inkonsistensi antar unassigned variables
🔗 ARC CONSISTENCY (AC-3)
Arc Xᵢ→Xⱼ KONSISTEN jika: ∀x ∈ Dᵢ, ∃y ∈ Dⱼ: (x,y) memenuhi constraint Xᵢ↔Xⱼ Jika ada x ∈ Dᵢ yang tidak punya y valid → hapus x dari Dᵢ Jika Dᵢ berubah → masukkan semua (Xₖ, Xᵢ) ke queue
Aspek Forward Checking Arc Consistency
Kecepatan ✅ Lebih cepat ❌ Lebih lambat
Pruning ❌ Kurang efektif ✅ Lebih efektif
Deteksi Arc var baru saja Semua arc

k-consistency: 1=node, 2=arc, 3=path | Strongly k: konsisten untuk semua 1..k

💡 TIPS SOAL CSP (Q1)

  • Domain: nilai valid tiap variabel
  • Constraint: semua batasan antar variabel
  • Graph: node=var, edge=ada constraint binary
  • FC: tampilkan domain tersisa setelah tiap assign
  • BT: gambar tree, tandai X pada branch yg backtrack
  • Soal Jadwal/SKS: var=Kelas/MK, domain=Dosen/Waktu, constraint=Tidak boleh bentrok (contoh: AllDiff).

⚡ QUANTIFIER RULES
∀ (Universal) → konektivitas utama HARUS ⇒
∀x Karyawan(x) ⇒ MendapatGaji(x)
[Semua karyawan mendapat gaji]

∃ (Existential) → konektivitas utama HARUS ∧
∃x Karyawan(x) ∧ MendapatBonus(x)
[Ada karyawan yang mendapat bonus]
❌ SALAH: ∀x P(x) ∧ Q(x) → berarti semua x memenuhi P DAN semua x memenuhi Q ❌ SALAH: ∃x P(x) ⇒ Q(x) → benar meski tidak ada x yang penuhi P! Duality: ¬∀x P ≡ ∃x ¬P | ¬∃x P ≡ ∀x ¬P Commutativity: ∀x∀y ≡ ∀y∀x | ∃x∃y ≡ ∃y∃x NON-commutative: ∃x∀y P ≠ ∀y∃x P ← HATI-HATI!
🔄 KONVERSI FOL → CNF (7 LANGKAH)
  1. Eliminasi biconditional (⟺):
    A⟺B → (A⇒B) ∧ (B⇒A)
  2. Eliminasi implikasi (⇒):
    A⇒B → ¬A∨B
  3. Pindah ¬ ke dalam:
    ¬(A∧B) → ¬A∨¬B | ¬(A∨B) → ¬A∧¬B
    ¬∀x P → ∃x ¬P | ¬∃x P → ∀x ¬P | ¬¬P → P
  4. Standardize variabel: tiap quantifier pakai nama unik
  5. Skolemize — eliminasi ∃:
    ∃x bebas → ganti dengan konstanta baru (C₁, C₂,...)
    ∃x di bawah ∀y₁...∀yₙ → ganti dengan fungsi f(y₁,...,yₙ)
  6. Drop ∀ — semua variabel masih universally quantified
  7. Distribusikan ∨ atas ∧:
    A∨(B∧C) → (A∨B) ∧ (A∨C)
Hasil CNF: konjungsi (∧) dari klause-klause, tiap klause adalah disjungsi (∨) literal
⚙ RESOLUTION
PRINSIP: C₁ = {L, l₁, l₂,...} C₂ = {¬L, m₁, m₂,...} Resolvent = {l₁,l₂,...,m₁,m₂,...} (hapus L dan ¬L)
PROOF BY REFUTATION (SOAL Q2c):
1. Tulis semua KB dalam CNF
2. NEGATE goal → tambahkan ¬Goal ke KB dalam CNF
3. Resolve pasangan klause sampai → empty clause { }
4. Empty clause = KONTRADIKSI → Goal terbukti ✓
UNIFICATION: UNIFY(p,q) = θ → SUBST(θ,p) = SUBST(θ,q) Contoh: UNIFY(Knows(x,Obama), Knows(Bill,y)) = {x/Bill, y/Obama}
Contoh Resolusi (Q2c style):
KB: ¬Karyw(x)∨¬MgP(x,A)∨¬MsP(x,A)∨Bonus(x) [R1 CNF] ¬Bonus(x)∨¬MsP(x,C)∨Pujian(x) [R3 CNF] Karyw(Ali), MgP(Ali,A), MsP(Ali,A), MsP(Ali,C) [facts] Prove: Pujian(Ali) → negate: ¬Pujian(Ali) Resolve R1+facts → Bonus(Ali) Resolve R3+facts → ¬Bonus(Ali)∨Pujian(Ali) Resolve with Bonus(Ali) → Pujian(Ali) Resolve with ¬Pujian(Ali) → {} ← KONTRADIKSI → TERBUKTI! ✓

📐 FUNGSI KEANGGOTAAN
Linear Naik [a, b]
Linear Turun [a, b]
Linear Naik: μ(x) = x−ab−a  [a ≤ x ≤ b]
Linear Turun: μ(x) = b−xb−a  [a ≤ x ≤ b]
Segitiga [a, b, c]
Trapesium [a, b, c, d]
Segitiga: x−ab−a [a≤x≤b] | c−xc−b [b≤x≤c]
Trapesium: x−ab−a [a≤x≤b] | 1 [b≤x≤c] | d−xd−c [c≤x≤d]
Kurva-S (Sigmoid) [α, β, γ] — β = (α+γ)/2
Kurva-S (Sigmoid) Naik: (β = α+γ2 = titik tengah, μ=0.5)
μ(x) = 0 ; x ≤ α  |  2·(x−α)2(γ−α)2 ; α < x ≤ β
μ(x) = 1 − 2·(γ−x)2(γ−α)2 ; β < x < γ  |  1 ; x ≥ γ
TIPS HITUNG CEPAT: - Jika x tepat di titik tengah β, maka μ(x) = 0.5 - Jika x < α atau x> d/γ, maka μ(x) = 0 - Jika x di plateau trapesium [b,c], maka μ(x) = 1

🔵 FUZZY MAMDANI — 4 TAHAP
TAHAP 1: FUZZIFIKASI

Hitung μ(x) setiap input untuk setiap himpunan fuzzy

TAHAP 2: INFERENSI / RULE EVALUATION
Operator anteseden: AND → min(μ₁, μ₂) ← ambil yang TERKECIL OR → max(μ₁, μ₂) ← ambil yang TERBESAR NOT → 1 - μ Firing strength α = hasil operator di anteseden Output: clip/scale MF konsekuen pada level α

Contoh: IF x is A3 (μ=0.0) OR y is B1 (μ=0.1) → z is C1 (0.1)

Contoh: IF x is A2 (μ=0.2) AND y is B2 (μ=0.7) → z is C2 (min=0.2)

TAHAP 3: AGREGASI

Gabung semua output rule → SATU himpunan fuzzy tunggal (ambil MAX di setiap titik z)

TAHAP 4: DEFUZZIFIKASI
Metode Cara
COG/COA Centre of Gravity: ∫z·μ(z)dz / ∫μ(z)dz
BOA Bisector of Area: garis bagi area jadi 2 sama
MOM Mean of Maximum: rata-rata nilai dengan μ tertinggi
SOM Smallest of Maximum: nilai terkecil dari μ max
LOM Largest of Maximum: nilai terbesar dari μ max
📊 COG MAMDANI (DISKRIT)
z* = Σ(zᵢ · μ(zᵢ))Σμ(zᵢ)

🔴 FUZZY SUGENO
PERBEDAAN UTAMA dari Mamdani:
Konsekuen = fungsi matematika, BUKAN himpunan fuzzy
→ Orde-0: z = k (konstanta, contoh: 90%, 60%, 30%)
→ Orde-1: z = ax + by + c (fungsi linear dari input)
DEFUZZIFIKASI SUGENO — WEIGHTED AVERAGE (WA):
z* = Σ(μᵢ · kᵢ)Σμᵢ

dimana:
μᵢ = firing strength rule ke-i (hasil AND/OR anteseden)
kᵢ = output rule ke-i. (Jika Orde-1 (z=ax+by), hitung kᵢ substitusi nilai crisp input ke polinomial!)
Contoh Sugeno Orde-1 (Prediksi AC):
Input: Suhu (x) = 35, Orang (y) = 15
Rule 1: IF Panas AND Ramai THEN z = 2x + 3y + 10. (Misal μ₁ = 0.6)
→ Hitung k₁: substitusi x=35, y=15
    k₁ = 2(35) + 3(15) + 10 = 70 + 45 + 10 = 125

Rule 2: IF Panas AND Sepi THEN z = 1.5x + y + 5. (Misal μ₂ = 0.2)
→ Hitung k₂: substitusi x=35, y=15
    k₂ = 1.5(35) + 15 + 5 = 52.5 + 20 = 72.5

WA = 0.6·125 + 0.2·72.50.6+0.2 = 75 + 14.50.8 = 89.50.8 ≈ 111.87
